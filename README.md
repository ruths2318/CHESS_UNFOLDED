# CHESS_UNFOLDED

To run the code:
1. Create the virtual environment : python -m venv myenv
2. Activate the virtual environment : myenv\Scripts\activate
3. Install all the dependencies : pip install -r requirements.txt
4. Run the server: python manage.py runserver

In the website, upload the .pgn file present in data\sample or any other .pgn file.It generates the summary of the game.
